## 7. TRANSFER STOK ANTAR TOKO / CABANG (TANPA PEMBAYARAN KAS)

**Asumsi:** Dua toko (A dan B) dengan pembukuan terpisah, namun satu pemilik. Transfer barang dicatat menggunakan **REKENING KORAN PUSAT (04.01.003)** agar tidak timbul piutang/hutang fiktif.

### 7.1 Toko A mengirim barang ke Toko B (harga pokok Rp10.000.000)

**Jurnal di Toko A (Pengirim):**

| Akun | Debit | Kredit |
|------|-------|--------|
| REKENING KORAN PUSAT (04.01.003) | 10.000.000 |  |
| PERSEDIAAN BARANG (Toko A) |  | 10.000.000 |

**Jurnal di Toko B (Penerima):**

| Akun | Debit | Kredit |
|------|-------|--------|
| PERSEDIAAN BARANG (Toko B) | 10.000.000 |  |
| REKENING KORAN PUSAT (04.01.003) |  | 10.000.000 |

> **Penjelasan:** Akun Rekening Koran Pusat berfungsi sebagai penampung transfer aset internal. Saldo akun ini di setiap toko akan menunjukkan posisi bersih klaim pusat terhadap toko tersebut. Pada konsolidasi, saldo ini saling menghapus.

### 7.2 Transfer dengan biaya angkut ditanggung pusat (via kas toko)
**Transaksi:** Toko A mengirim barang, membayar ongkir Rp200.000 dari kas toko A.

**Jurnal di Toko A:**

| Akun | Debit | Kredit |
|------|-------|--------|
| REKENING KORAN PUSAT | 200.000 |  |
| KAS DI TOKO A |  | 200.000 |

**Tidak ada jurnal di Toko B untuk ongkir.** Biaya angkut dibebankan ke pusat (rekening koran pusat).

## 11. PENUTUPAN LABA RUGI (AKHIR TAHUN)

**Langkah 1:** Tutup semua akun pendapatan (kredit) ke LABA RUGI BERJALAN.

| Akun | Debit | Kredit |
|------|-------|--------|

| LABA RUGI BERJALAN |  | (total pendapatan) |

**Langkah 2:** Tutup semua akun beban dan kontra-pendapatan (debit) ke LABA RUGI BERJALAN.

| Akun | Debit | Kredit |
|------|-------|--------|
| LABA RUGI BERJALAN | (total beban) |  |
| RETUR PENJUALAN |  | (total) |
| POTONGAN DISKON PENJUALAN |  | (total) |

| BIAYA KIRIM PENJUALAN |  | (total) |
| PENYESUAIAN STOK MINUS |  | (total) |
| POTONGAN DISKON PEMBELIAN |  | (total) |
| BEBAN GAJI KARYAWAN |  | (total) |
| ... (semua beban lainnya) |  | (total) |

**Langkah 3:** Tutup laba/rugi bersih ke MODAL.

Jika laba: Debit LABA RUGI BERJALAN, Kredit MODAL.  
Jika rugi: Debit MODAL, Kredit LABA RUGI BERJALAN.

## Catatan Penting

1. **Akun REKENING KORAN PUSAT (04.01.003)** digunakan khusus untuk transfer aset internal (persediaan, kas antar toko, dll) tanpa melibatkan kas. Jika suatu saat Anda ingin menyetorkan uang dari satu toko ke toko lain, gunakan juga akun ini.
2. **Tidak ada akun "Persediaan dalam Perjalanan"** dalam jurnal di atas. Jika ingin menggunakannya, silakan tambahkan sendiri.
3. Semua jurnal mengasumsikan penggunaan PPN 11%. Sesuaikan jika tarif berubah.
4. Untuk transaksi antar toko dengan pembukuan terpisah, pastikan setiap toko mencatat sesuai jurnal di atas. Pada laporan konsolidasi, saldo Rekening Koran Pusat akan saling menghapus.
