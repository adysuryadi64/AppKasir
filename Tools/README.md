# Tools

Folder ini berisi installer tools yang dibutuhkan untuk development AppKasir.
Jalankan `Setup-DevEnvironment.ps1` di root workspace untuk install semua otomatis.

| File | Keterangan |
|---|---|
| `gh_x.x.x_windows_amd64.msi` | GitHub CLI — untuk auto-publish release ke GitHub |

## Update GitHub CLI
Kalau ada versi baru, download dari https://github.com/cli/cli/releases/latest
pilih `gh_x.x.x_windows_amd64.msi` lalu replace file lama di folder ini.
