# AppKasir 2026

Sistem Point-of-Sale (POS) dan Akuntansi berbasis Windows Forms (VB.NET) untuk ritel menengah hingga besar.

## Tentang

AppKasir menggabungkan transaksi kasir harian dengan pembukuan double-entry secara real-time. Stok, jurnal, piutang, dan hutang selalu sinkron otomatis di setiap transaksi.

## Fitur Utama

- Penjualan & pembelian multi-item dengan barcode scanner
- Berbagai metode pembayaran (tunai, transfer, QRIS, tempo)
- Manajemen stok toko & gudang dengan sistem counter
- Jurnal akuntansi otomatis (double-entry bookkeeping)
- Laporan lengkap: laba rugi, neraca, kartu stok, piutang/hutang
- Hak akses per pengguna
- Cetak nota thermal, inkjet, dan PDF
- Multi-cabang & sinkronisasi data

## Teknologi

- **Bahasa:** Visual Basic .NET
- **Framework:** .NET Framework 4.7.2+
- **Database:** MySQL 5.7+ / 8.0+
- **UI:** Windows Forms
